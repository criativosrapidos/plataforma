# Proposta genérica — Criativos Rápidos

Proposta comercial sem marca de cliente, para enviar a qualquer potencial cliente.
Pacotes e planos conforme `../definicao-planos.md`. Logo provisório até chegar o arquivo oficial.

- `proposta-criativos-rapidos.pdf` — versão pronta para enviar (7 slides, 16:9, amarelo e preto)
- `index.html` — fonte editável (abra no navegador para ver os slides)

Para gerar o PDF de novo após editar o HTML, use o Chromium/Playwright
(`page.pdf` com 1920x1080 e `printBackground: true`).
