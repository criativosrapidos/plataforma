# Rastreia Van — rastreiavan.com.br

Micro SaaS de rastreamento de van escolar com notificações automáticas no celular (push).

- `index.html` — site / landing page
- `marca.html` — guia de identidade visual
- `assets/` — logo (SVG e PNG), símbolo/ícone do app, favicon e CSS com as cores da marca
- `instagram/imagens/` — posts, carrossel, stories, foto de perfil e capas de destaque
- `instagram/legendas.md` — bio, legendas, hashtags e ordem de postagem
- `PROMPT.md` — prompt para construir o produto em outro Claude
